# 导演拆镜检查表

## 段落级

- 这一段结束时，观众必须新增理解什么？
- 人物行动的动机是否在动作发生前出现？
- 人物、目标物和出入口的空间关系是否先建立？
- 情绪是否有明确变化，而不是一组无因果的漂亮画面？
- 声音预演是否能单独听懂事件顺序？

## 镜头级

每个镜头必须回答：

1. 叙事用途：建立关系、提问、回应、施法、行动、结果或反应。
2. 起始状态：人物位置、视线、姿态、手势和道具状态。
3. 结束状态：为下一镜留下什么可连续的状态。
4. 表演目标：人物想做什么，以及观众应读到什么情绪。
5. 景别理由：为什么是全景、中景、近景或特写。
6. 运镜理由：机位移动是否服务信息，而不是制造无意义晃动。
7. 主动作：一个片段只保留一个主动作。

## 景别用途

- 全景/中远景：建立人物与目标物、门、场景的空间关系。
- 中景：对白、手势和人物关系；默认景别。
- 近景：确认关键反应或动作细节，持续时间应短。
- 特写：只用于必须放大的线索、表情或冲击；必须写明理由。

## 段落落地检查

写清“动机 → 准备 → 行动 → 结果 → 反应”，并为每步标注观众应读到的信息。锁定人物与目标物的画面左右关系；如需越轴，先用建立镜头重新说明空间。
