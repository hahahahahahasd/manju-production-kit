# 失败与重试规则

## 提交结果未知

1. 先查询 ComfyUI `/queue`、`/history/<promptId>`、已有 run 文件和远端输出。
2. 未确认前标记 `unknown`，停止后续提交。
3. 找到原 promptId 后继续收片；确认从未提交后才允许重新提交。

## 返修记录

每次返修必须记录：

- 症状：观众实际看到的问题。
- 可能原因：关键帧、镜头设计、动作提示、身份约束、模型或剪辑问题。
- 本次唯一改变：只改变最可能的原因，便于判断是否有效。

同类失败连续两次后，禁止继续仅换种子。必须检查：

1. 镜头是否承担了多个主动作。
2. 起止帧和空间关系是否明确。
3. 身份参考是否真正接入工作流。
4. 景别是否过近，导致模型放大面部和肢体缺陷。
5. 是否应拆成两个镜头或改用更稳定的中景。

## 审查失效

以下任一变更都会使原审查失效：源图、角色参考、场景参考、提示词、负面提示、模型、采样参数、帧数、音频、裁切、变速、补帧或镜头顺序。
