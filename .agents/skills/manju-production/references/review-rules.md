# 审查与状态规则

## 状态链

`design_ready → keyframe_ready → generation_ready → submitted → generated → technical_pass → single_shot_pass → continuity_pass → adopted`

补充状态：

- `blocked`：缺少必需资产、音频、关键帧或导演信息。
- `review_pending`：已有结果但尚未完成人工观看。
- `rejected`：确认不合格，禁止用于正式剪辑。

任何上游资产、提示词、时长、裁切或音频改变，相关镜头至少退回 `generation_ready`，并清除旧的视觉通过状态。

## 三遍观看

1. **静音观看**：检查人物身份、场景、动作、构图、重复动作和画面瑕疵。
2. **只听声音**：检查对白信息、停顿、反应、音色和事件顺序。
3. **声画合看**：检查说话人、口型、动作节拍、信息到达时间和情绪反应。

## 单镜通过条件

- 人物身份、服装、发型和年龄与角色表一致。
- 环境、光线和目标物与段落空间一致。
- 主动作完整，没有重复、倒退、循环或突然跳变。
- 构图没有用低清裁切放大掩盖问题。
- 对白时正确人物动嘴，其他人物没有抢口型。

## 相邻镜头连续性

- 前一镜结束姿态能接到后一镜开始姿态。
- 视线方向、行动方向、人物左右位置和目标物保持一致。
- 特效颜色、强度和作用位置连续。
- 动作不能在切镜后重新开始，也不能缺失关键中间因果。
- 只有连续性审查通过的镜头才能进入正式段落剪辑。
