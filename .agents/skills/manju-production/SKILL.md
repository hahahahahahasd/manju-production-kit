# 漫剧生产流程

## 开始前

1. 阅读当前项目的状态文件，以及当前段落的 `direction.md`、`shots.json` 和 `reviews.json`；不存在的文件先建立，不得假定已审过。
2. 运行 `node .agents/skills/manju-production/scripts/validate-sequence.mjs --shots <shots.json>`。
3. 查询现有 ComfyUI 队列、历史 promptId 和输出；结果未知时禁止重复提交。

## 标准流程

1. **段落导演设计**：先明确段落目的、观众必须读懂的信息、人物关系、空间轴线和表演变化，再拆镜头。
2. **声音预演**：对白、停顿、反应和音效先形成可听节奏；未通过听审的克隆音色不能进入正式成片。
3. **关键帧准备**：角色三面图、服装、场景图和空间关系必须实际接入每个可见人物镜头；记录文件和 SHA256。
4. **生成准入**：镜头卡只有同时达到 `generation_ready`、关键帧通过、连续性准备通过、所需音频通过，才允许进入 GPU 队列。
5. **串行生成与收片**：沿用现有 ComfyUI 单队列；维持 2–3 个已核查任务，但禁止用未经核查的镜头填队。
6. **三层审查**：先技术审查，再单镜审查，最后相邻镜头连续性审查。三层都通过才可标记 `adopted`。
7. **段落交付**：先交付完整可理解的小段落，再扩到下一段；禁止仅凭单帧或单镜通过宣称成片合格。

## 硬规则

- 每个镜头必须有叙事目的、起止状态、表演目标、空间关系、景别理由、运镜意图和连续性检查项。
- 有可见人物时必须引用角色资产；引用必须可追溯且哈希匹配。
- 对白镜头必须核对说话人、声音、嘴型和画面焦点，不能出现非说话人物动嘴。
- 对话默认使用中景或更宽景别；特写必须写清叙事理由。不得靠裁切放大掩盖素材问题。
- 一个 AI 视频片段只承担一个主动作；重复动作、来回摆动、无因果动作均不通过。
- 被拒绝的素材不得继续参与正式剪辑；任何源图、音频、提示词、裁切或时长变更都会使原审查失效。
- 重试必须记录“症状、可能原因、本次唯一改变”。同类失败连续两次后停止换种子，转为诊断镜头设计或工作流。
